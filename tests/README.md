# 테스트 (리팩토링 안전망)

리팩토링 **전** 코드(`index.html`)의 동작을 그대로 기록해 둔 **특성 테스트(characterization test)** 입니다.
"이게 맞는 동작인가"가 아니라 "지금 이렇게 동작한다"를 고정해 두었습니다.
그래서 리팩토링 후에 테스트가 깨지면 동작이 바뀌었다는 뜻입니다.

## 실행

```bash
npm install
```

```bash
npm test
```

- 설치된 **Chrome**으로 화면 없이(headless) 실행합니다. 브라우저를 따로 내려받지 않습니다.
- Chrome이 없으면 `npx playwright install chromium`으로 브라우저를 받은 뒤 `PW_CHANNEL=` (빈 값)으로 실행하세요.
- 전체 59개, 약 1~2분 걸립니다. 부분만 돌릴 때는 아래 명령을 쓰세요.

| 명령 | 내용 |
|---|---|
| `npm run test:logic` | 게임 규칙: 표적 일정, 명중 판정, 점수 계산, 장전, 봇 AI (골든 스냅샷) |
| `npm run test:ui` | 혼자 연습, 조작(클릭·우클릭·휠·마우스), 대기실·봇 대결, 엔딩·결과, 이 브라우저 랭킹, 초대 QR·링크 |
| `npm run test:multi` | 여러 탭으로 하는 대결: 참가·거절·나가기, 분할/공유 화면 경기, 연결 끊김 |
| `npm run test:online` | 전체 랭킹 조회·점수 등록, 실시간 열린 방 목록 (가짜 Supabase) |

특정 테스트만 돌리려면 `npx playwright test -g "공유"`처럼 이름 일부를 넘기면 됩니다.

## 외부 서비스는 모두 가짜

테스트는 인터넷에 연결하지 않습니다. **실제 Supabase(온라인 랭킹)에도 점수가 올라가지 않습니다.**

- **CDN 스크립트**(PeerJS, QR, Supabase): 요청을 모두 막고 [`harness/fakes.js`](harness/fakes.js)의 가짜로 바꿔 끼웁니다.
- **PeerJS**: 같은 브라우저의 탭끼리 `BroadcastChannel`로 연결합니다. 방장 탭과 참가자 탭을 나란히 열어 실제처럼 대결합니다.
- **Supabase**: 점수는 `localStorage`, 열린 방 목록은 `BroadcastChannel`에 저장합니다.
- **`config.js`**: 테스트에서는 가짜 주소·키로 바꿔서 보냅니다. 실제 키는 쓰이지 않습니다.
- **시간 가속(warp)**: 60초 경기를 기다리지 않도록 `performance.now`, `requestAnimationFrame`, `setTimeout`을 빠르게 돌립니다.
  - 봇이 없는 경기는 20배(약 3초)입니다.
  - 봇이 있는 경기는 3배(약 20초)입니다. 게임이 프레임 간격을 0.05초로 자르기 때문에 더 빠르게 돌리면 봇이 표적을 따라가지 못합니다.
- 테스트 주소는 `http://sniper.test:4173/`입니다. 브라우저가 127.0.0.1로 연결합니다. `localhost`로 열면 게임이 "내 PC 전용 주소"로 판단해 QR을 숨기기 때문입니다.

## 리팩토링할 때 고칠 곳은 한 파일

테스트 본문은 게임 코드에 직접 닿지 않습니다. 게임과 맞닿는 부분은 모두 [`harness/app.js`](harness/app.js)에 모아 두었습니다.

- **`SEL`**: 화면 요소 선택자(`#btnSolo`, `#lobbyCode` …). HTML id를 바꾸면 여기만 고치세요.
- **`SEAM`**: 게임 내부 함수·상태를 꺼내는 통로입니다. 지금은 최상위 전역 이름(`buildSchedule`, `Game`, `Bot`, `match`, `net`, `lobby` …)을 그대로 씁니다.
  - 코드를 ES 모듈이나 객체로 옮기면 전역 이름이 사라집니다.
  - 그때는 게임 쪽에서 `window.__SD__ = { buildSchedule, Game, ..., get match(){...} }`를 열어 주거나, 이 문자열의 이름만 새 위치로 바꾸면 됩니다.
- 가짜 PeerJS·Supabase는 지금 게임이 쓰는 API(`new Peer`, `peer.connect`, `conn.send`, `sb.from().select().order().limit()`, `channel().track()` …)만 흉내 냅니다.
  - 리팩토링하면서 이 라이브러리들을 다른 방식으로 부르게 되면 [`harness/fakes.js`](harness/fakes.js)에도 맞춰 넣어야 합니다.

다른 HTML 파일을 테스트하려면 `SD_PAGE`를 지정하세요. 예) `SD_PAGE=legacy/sniper-duel-legacy.html npm run test:ui`
단, 내부 이름이 다른 파일은 `SEAM`이 맞지 않아서 게임 내부를 들여다보는 테스트가 실패합니다.
지금 `legacy/sniper-duel-legacy.html`로 화면 테스트(ui·online·multi 38개)를 돌리면 14개만 통과합니다.

## 골든 스냅샷

[`__snapshots__/logic.spec.js/`](__snapshots__/logic.spec.js/)의 JSON 파일은 리팩토링 전 코드로 만든 **기준값**입니다.

- 같은 시드의 난수 수열, 표적 일정 전체, 시각별 표적 위치
- 고정 시드로 60초 동안 플레이한 봇 결과(난이도별, 공유 화면 3명), 난이도별 평균 점수

리팩토링은 동작을 바꾸지 않는 작업이므로 스냅샷이 달라지면 안 됩니다.
게임 규칙을 **일부러** 바꾼 경우에만 `npm run test:update`로 기준값을 다시 만들고, 바뀐 JSON 차이를 검토한 뒤 커밋하세요.

검증: 아래 세 가지를 일부러 바꾼 복사본으로 돌려 보았고, 각각 테스트가 실패하는 것을 확인했습니다.

- 헤드샷 배율 1.5 → 2
- 표적 간격 1.3 → 1.35초
- [대기실로] 갈 때 봇을 빼는 버그

## 테스트가 기록한 "현재 동작" 중 이상해 보이는 것

아래는 고치지 않고 **지금 모습 그대로** 테스트에 고정해 두었습니다.
일부러 고치면 해당 테스트의 기대값도 함께 바꾸세요. 더 자세한 내용은 [`../docs/smells.md`](../docs/smells.md)에 있습니다.

| 테스트 | 현재 동작 |
|---|---|
| `logic` › 봇 난이도별 평균 점수 | **쉬움 봇(평균 7,064점)이 보통 봇(6,281점)보다 점수가 높습니다.** 어려움 봇은 10,983점입니다. |
| `ui` › [코드 복사]·[링크 복사] | http 주소(LAN 서버 등)에서는 [코드 복사]가 실제로 복사하지 못하고 `방 코드: XXXXX`만 보여 줍니다. [링크 복사]는 대체 경로가 있어서 복사됩니다. |
| `online` › 불러오기 실패 | 온라인 랭킹을 불러오지 못하면 오류 문구만 나오고, 이 브라우저 기록으로 대체하지 않습니다. |
| `online` › 누적/최고 점수 표 | 랭킹의 '내 줄' 강조는 표를 그린 순간의 닉네임을 기준으로 합니다. 닉네임을 입력해도 표를 다시 그리지 않습니다. |
